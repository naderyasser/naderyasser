### hey there 👋

backend developer who actually enjoys debugging at 3am (questionable life choices, i know).

currently building stuff with nodejs, express, and nestjs. sometimes i touch python when flask or django makes sense. learning laravel because why not add more frameworks to the collection.

**the usual stack:**
- **backend:** node.js, express, nestjs, flask, django, laravel
- **databases:** mongodb, mysql, postgresql
- **tools:** linux, docker, nginx, git, bash
- **languages:** javascript, typescript, python, php, c++

**what i actually do:**
- build apis that (hopefully) don't crash in production
- architect backend systems and pray they scale
- security stuff when things get spicy
- fix bugs that shouldn't exist but somehow do
- optimize code when everything runs slower than my coffee maker
- learn new things and immediately forget the old ones

> make it work first. make it right later. make it fast if someone complains.
