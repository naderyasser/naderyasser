## how to edit this thing

yeah so you wanna customize this readme? cool. here's how without making it look like chatgpt made it:

### the header animation
```markdown
<img src="https://capsule-render.vercel.app/api?type=waving&color=...&text=YOUR_NAME" />
```
- change `text=Nader%20Yasser` to your name (use %20 for spaces)
- `color=0D1117,1a1a1a,0D1117` = dark theme colors (hex codes)
- `fontSize=80` = bigger/smaller text
- mess with it till it looks decent

### the typing thing
```markdown
https://readme-typing-svg.herokuapp.com?font=Fira+Code&...&lines=Line1;Line2;Line3
```
- add your own lines separated by `;`
- `duration=4000` = how long each line shows (milliseconds)
- `pause=1000` = pause between lines
- don't make it cringe. keep it real.

### that creepy theater gif
```markdown
<img align="right" alt="Theater" width="350" src="YOUR_GIF_URL">
```
- find a gif you like on giphy or wherever
- right click → copy image address
- paste the url in `src=""`
- `width="350"` = size (bigger number = bigger gif)
- `align="right"` puts it on the right side

**finding gifs that don't suck:**
- giphy.com - search what you want
- tenor.com - more options
- or just google "animated gif [whatever]"

### the stats cards

**main stats card:**
```markdown
github-readme-stats.vercel.app/api?username=YOUR_USERNAME&theme=dark&bg_color=0D1117...
```
- change `username=naderyasser` to yours
- colors: `bg_color`, `title_color`, `text_color` (hex codes without #)
- `hide_border=true` = no border (cleaner look)

**streak stats:**
```markdown
github-readme-streak-stats.herokuapp.com/?user=YOUR_USERNAME&theme=dark...
```
- same deal, change username
- customize colors if you want
- or just copy mine, i don't care

**language stats:**
```markdown
top-langs/?username=YOUR_USERNAME&layout=compact...
```
- shows what languages you use most
- `langs_count=8` = how many languages to show
- `layout=compact` = smaller, fits better

### the code block
```markdown
​```js
// your code here
​```
```
- just regular markdown code blocks
- change `js` to whatever language (python, php, etc)
- write whatever you want
- keep it short and real

### making it look human (not ai)

**do:**
- use lowercase. looks more casual
- short sentences
- some typos are fine (not too many tho)
- personal voice. say "i" not "we"
- be direct. no corporate talk
- add personality. jokes, whatever

**don't:**
- use fancy words for no reason
- over-explain everything
- make it too polished
- copy-paste ai stuff
- be fake enthusiastic
- use too many emojis

### color scheme explained

```
0D1117 = dark background (almost black)
1a1a1a = slightly lighter dark
4a4a4a = gray for text
666666 = lighter gray
888888 = even lighter gray
555555 = medium gray for icons
```

want it darker? use lower numbers (like 000000).
want it lighter? use higher numbers.

### badges and links

```markdown
[![badge-name](badge-url)](link-url)
```
- find badges at shields.io
- customize colors with `?color=hexcode`
- keep it simple. too many badges = spam

### protips

1. **test locally first** - create a test repo, see how it looks
2. **mobile matters** - check on phone, not just desktop
3. **less is more** - don't add every feature you find
4. **be consistent** - stick to your color scheme
5. **update it** - change stuff when you learn new things

### if something breaks

- check the url is correct (one typo = broken image)
- some gifs don't work on github (try different ones)
- stats not showing? username might be wrong
- cache issues? add `?v=1` to the url (change number to refresh)

### final notes

this readme is supposed to be dark, minimal, and actually show who you are. not some polished corporate thing. 

keep it real. add your own style. break some rules. 

if it works, it works.
